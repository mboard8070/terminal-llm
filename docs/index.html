> Maude

Personal AI Terminal Assistant

Purpose

Maude is a personal, terminal-based AI assistant that connects to Google Workspace to help its user manage everyday productivity tasks from the command line. It can read and send emails, manage calendar events, browse and organise files on Google Drive, edit spreadsheets and presentations, look up contacts, and interact with YouTube — all through natural-language conversation in a terminal interface.

Maude is a private, single-user application built for personal use. It is not available for public sign-up or download.

Google Workspace Integration

Maude connects to the following Google services on behalf of the authenticated user:

Gmail Google Drive Google Sheets Google Slides Google Calendar Google Contacts YouTube

Permissions Requested

  • Read and send email (Gmail)
  • Read and manage files (Google Drive)
  • Read and edit spreadsheets (Google Sheets)
  • Read and edit presentations (Google Slides)
  • Read and manage calendar events (Google Calendar)
  • Read and manage contacts (Google Contacts)
  • Read and manage YouTube data (YouTube)

These permissions are used solely to enable the assistant's functionality. Data is accessed only on behalf of the authenticated user and only when explicitly requested through the assistant.

How It Works

Maude runs as a local terminal application. When the user asks a question or gives a command involving a Google service, Maude calls the relevant Google API, retrieves the data, and presents it in the terminal. No data is stored, forwarded, or used for any purpose other than answering the user's request.
